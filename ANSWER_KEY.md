# ANSWER_KEY - список намеренных ошибок

## Ошибка №1
**Функция:** `gainExperience` в `CharacterOperations.kt`

**Строка:** 186

**Тип:** Логическая (граничное условие)

**Суть:** Использовано `>` вместо `>=` в условии цикла `while (experience > xpForNextLevel(level))`.

**Проявление:** При накоплении ровно 100 XP (порога для 2 уровня) персонаж не повышает уровень.

**Как найти:** Тест на граничное значение - `gainExperience(character, 100)` должен повысить уровень до 2.

**Исправление:** Заменить `>` на `>=`.
